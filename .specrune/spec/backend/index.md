## How to Fill These Guidelines

For each file:

1. Write down what this project **actually does**, not what it should do.
2. Quote real code from this repository as the example.
3. Name the patterns that are forbidden here, and the incident that made them forbidden.
4. Record the mistakes the team has already made — a mistake documented once is a
   mistake the next contributor does not repeat.

These files are read by AI assistants and by new team members. Both need the same
thing: enough specifics to produce code that looks like it was written here.

---

**Language**: Write these documents in **English**.
